# AGENTS.md

Правила для AI-агентов и контрибьюторов проекта «Ведьмак: НРИ — справочник правил».

## Цель

Сделать удобный статический справочник правил НРИ «Ведьмак» на VitePress + Vue, не искажая оригинальный текст книги.

## Незыблемые правила

1. **Не переписывать правила.** Формулировки, пунктуация и авторские вставки сохраняются как в книге. Разрешено: склеивать переносы строк, убирать колонтитулы, исправлять OCR-артефакты (`1Л6` → `1d6`, `IdlO` → `1d10`), нормализовать пробелы.
2. **Не придумывать правила и числа.** Если данных нет в PDF, оставь `TODO` и укажи страницу, а не заполняй по памяти.
3. **Источник обязателен.** У каждой страницы — `Источник: стр. N`; у каждой записи каталога — `sourcePage`.
4. **Сомнительное — сверять с изображением страницы.** Текстовая выгрузка может врать в таблицах, формулах и многоколоночной вёрстке.
5. **Не менять `_artifacts/` как источник.** Это рабочая папка с извлечённым текстом. Новые артефакты добавлять, старые не перезаписывать без причины.
6. **PDF не коммитить.** `Witcher.pdf` в `.gitignore`.
7. **Не использовать иллюстрации из книги.** Допустимы только иконки субстанций из Foundry-репозитория с атрибуцией в `_artifacts/web/assets/ICONS.md`.
8. **`llms.txt` генерируется плагином.** Не создавать статический `docs/public/llms.txt`; файлы `llms.txt` и `llms-full.txt` появляются при сборке через `vitepress-plugin-llms`.

## Структура контента

- Правила — Markdown в `docs/<section>/*.md`.
- Каталоги — JSON в `docs/.vitepress/data/*.json`.
- Схемы — Zod в `docs/.vitepress/schemas/*.ts`.
- Компоненты — `docs/.vitepress/theme/components/*.vue`.
- Навигация — `docs/.vitepress/navigation.ts`; после добавления страницы обнови сайдбар.

### Формат страницы

```md
---
title: Название
description: Краткое описание для поиска и llms.txt
---

# Название

Текст правил.

::: info Источник
Стр. 151–158 книги.
:::
```

Врезки книги — `::: info` или `::: tip` с сохранением заголовка и автора. Не превращать их в обычные абзацы.

### Формат записи каталога

- `id` — транслитерация, стабильная, без пробелов.
- `name` — как в книге.
- `sourcePage` — номер страницы PDF.
- Тексты эффектов — дословно.
- `schemaVersion` — в корне файла.

## Работа с PDF

- Постраничный текст: `_artifacts/pdf/pages/pNNN.txt`.
- Layout-версия: `_artifacts/pdf/witcher_layout.txt`.
- Карта разделов: `_artifacts/RESEARCH.md`.
- Рендеры для сверки: `_artifacts/samples/page_N.png`.
- Для новых страниц при необходимости рендерить через `pypdfium2` (150–200 dpi).

## Стиль

- Контент сайта — русский. Код, ID, имена файлов — английский.
- Заголовки и текст — Literata; интерфейс и таблицы — Inter.
- Не добавлять декоративные эмодзи в правила.
- Ссылки на другие разделы — относительные (`/combat/effects`).

## UI-правила таблиц

- Легенда/пояснение к таблице всегда идёт **до** таблицы, не после.
- Внутри рамки таблицы не должно быть пустых полос сверху и снизу: у `table` сбрасывать `margin`, у обёртки не добавлять лишний `padding`.
- Широкие таблицы — на страницах с `pageClass: wide-page`.
- Числовые колонки — `font-variant-numeric: tabular-nums`, выравнивание вправо.
