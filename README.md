# Ведьмак: НРИ — справочник правил

Неофициальный структурированный справочник по настольной ролевой игре «Ведьмак» (The Witcher RPG). Задача проекта — сделать правила удобными для поиска, фильтрации и использования за столом, не меняя оригинальные формулировки книг.

Актуальный план и handoff для следующей сессии — в [PLAN.md](./PLAN.md).

## Что уже есть

- Каркас сайта на VitePress + Vue 3.
- Светлая «пергаментная» тема и тёмный вариант.
- Навигация по всем разделам книги.
- Полный раздел магии: 177 заклинаний, 39 знаков, 62 инвокации, 31 ритуал, 17 порч и 14 магических даров с фильтрами и карточками; заклинания, знаки, инвокации, ритуалы и порча открываются в правом сайдбаре.
- Полный раздел боя: правила, 24 критических ранения, эффекты, магия, транспорт, лечение и Словесная дуэль.
- Создание персонажа: расы, жизненный путь, параметры, 50 навыков, проверки, развитие, репутация и 16 древ профессий.
- Профессии: одна страница с переключением между 16 профессиями — определяющие навыки, энергия, магические способности, навыки и стартовое снаряжение.
- Бестиарий: 12 классов, 28 чудовищ (30 вариантов) и 8 животных с фильтрами и полными блоками характеристик; скелеты, древни и шесть исключительных чудовищ добавлены из «Alzur's Tome of Magic».
- Ведьмаки: обзор, жизненный путь, снаряжение и мутагены.
- Руны и реликвии: руны, глифы, рунные и глифические слова, а также каталог реликвий в разделе «Ремесло».
- Ведущему: роль ведущего, награды, проклятия, персонажи ведущего и ведение кампании.
- Мир: обзор, Королевства Севера, Нильфгаард, Земли Старшего Народа, религии, союзы и лор магии; страницы мира собраны в интерактивные раскрывающиеся разделы.
- Шпаргалка и глоссарий: проверки, бой, состояния, лечение, сокращения и ключевые термины.
- Каталоги оружия и брони: 108 и 60 позиций, фильтры по книге, сортировка, подсчёт веса и цены, бейджи источника.
- Бомбы, ловушки, боеприпасы и улучшения арбалета: отдельная страница и разделы на странице оружия.
- Магические артефакты: отдельный подраздел снаряжения с уникальными предметами из дополнительных книг.
- Схемы данных и валидация каталогов.
- Генерация `llms.txt` и `llms-full.txt` плагином `vitepress-plugin-llms`.
- Поиск Pagefind с русской морфологией.
- Библиотека из 5 книг: каталог `books/README.md`, отдельные артефакты по каждой книге.
- Рабочая папка `_artifacts/` с извлечённым текстом PDF и исследованием.

## Стек

- [VitePress](https://vitepress.dev/) 1.6.4
- Vue 3 + TypeScript
- Pagefind для полнотекстового поиска
- `vitepress-plugin-llms` для LLM-версии сайта
- Zod для валидации JSON-каталогов
- Vercel для хостинга
- `.vercelignore` исключает PDF и рабочие артефакты из загрузки

## Быстрый старт

```bash

npm run check       # validate + build
```

## Конвейер контента

1. **Source.** PDF лежат в `books/` и не коммитятся. Постраничный текст и рендеры — в `_artifacts/books/<book-id>/`.
2. **Normalize.** Убираем колонтитулы, склеиваем переносы, чиним OCR-артефакты (`1Л6` → `1d6`, `IdlO` → `1d10`).
3. **Structure.** Правила — Markdown, каталоги — JSON. У каждой страницы и записи есть ссылка на книгу и страницу; для дополнительных книг — `sourceBook`.
4. **Verify.** Zod-схемы, проверка уникальности, сверка таблиц с координатами и рендерами.
5. **Build.** VitePress собирает статику; Pagefind индексирует; плагин генерирует `llms.txt`.

### Правила переноса текста

- Формулировки не переписываем.
- Исправляем только механические артефакты OCR и переносы строк.
- Врезки и цитаты выносим в `::: info` / `::: tip` с сохранением авторства.
- У каждой страницы указываем `Источник: стр. N`; для дополнительной книги — ещё и её название.
- У каждой записи каталога — `sourcePage`, для дополнительных книг — `sourceBook`.
- Спорные места сверяем с изображением страницы.
