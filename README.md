# Ведьмак: НРИ — справочник правил

Неофициальный структурированный справочник по настольной ролевой игре «Ведьмак» (The Witcher RPG). Задача проекта — сделать правила удобными для поиска, фильтрации и использования за столом, не меняя оригинальные формулировки книги.

## Что уже есть

- Каркас сайта на VitePress + Vue 3.
- Светлая «пергаментная» тема и тёмный вариант.
- Навигация по всем разделам книги.
- Каталог заклинаний с фильтрами по уровню, стихии и тексту (8 заклинаний для проверки интерфейса).
- Схемы данных и валидация каталогов.
- Генерация `llms.txt` и `llms-full.txt` плагином `vitepress-plugin-llms`.
- Поиск Pagefind с русской морфологией.
- Рабочая папка `_artifacts/` с извлечённым текстом PDF и исследованием.

## Стек

- [VitePress](https://vitepress.dev/) 1.6.4
- Vue 3 + TypeScript
- Pagefind для полнотекстового поиска
- `vitepress-plugin-llms` для LLM-версии сайта
- Zod для валидации JSON-каталогов
- Vercel для хостинга

## Конвейер контента

1. **Source.** PDF не коммитится. Постраничный текст и рендеры лежат в `_artifacts/pdf/`.
2. **Normalize.** Убираем колонтитулы, склеиваем переносы, чиним OCR-артефакты (`1Л6` → `1d6`, `IdlO` → `1d10`).
3. **Structure.** Правила — Markdown, каталоги — JSON. У каждой страницы и записи есть ссылка на страницу книги.
4. **Verify.** Zod-схемы, проверка уникальности, сверка таблиц с координатами и рендерами.
5. **Build.** VitePress собирает статику; Pagefind индексирует; плагин генерирует `llms.txt`.

### Правила переноса текста

- Формулировки не переписываем.
- Исправляем только механические артефакты OCR и переносы строк.
- Врезки и цитаты выносим в `::: info` / `::: tip` с сохранением авторства.
- У каждой страницы указываем `Источник: стр. N`.
- Спорные места сверяем с изображением страницы.

## Данные

- `docs/.vitepress/data/*.json` — каталоги.
- `docs/.vitepress/schemas/*.ts` — Zod-схемы.
- `schemaVersion` в каждом файле — для будущих миграций.
- Иконки субстанций: `_artifacts/web/assets/icons_svg/` (векторные, из Foundry-репозитория; атрибуция в `_artifacts/web/assets/ICONS.md`).

## Деплой

Проект рассчитан на Vercel:

- Build Command: `npm run docs:build`
- Output Directory: `docs/.vitepress/dist`
- Node.js 22

`vercel.json` уже содержит настройки. Для продакшена нужно заменить `hostname` в `sitemap` и `robots.txt` на реальный домен.
