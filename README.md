# Ведьмак: НРИ — справочник правил

Неофициальный структурированный справочник по настольной ролевой игре «Ведьмак» (The Witcher RPG). Задача проекта — сделать правила удобными для поиска, фильтрации и использования за столом, не меняя оригинальные формулировки книг.

## Стек

- [VitePress](https://vitepress.dev/) 1.6.4
- Vue 3 + TypeScript
- Pagefind для полнотекстового поиска
- `vitepress-plugin-llms` для LLM-версии сайта
- Zod для валидации JSON-каталогов
- Vercel для хостинга
- `.vercelignore` исключает PDF и рабочие артефакты из загрузки

## Конвейер контента

1. **Source.** PDF лежат в `books/` и не коммитятся. Постраничный текст и рендеры — в `_artifacts/books/<book-id>/`.
2. **Normalize.** Убираем колонтитулы, склеиваем переносы, чиним OCR-артефакты (`1Л6` → `1d6`, `IdlO` → `1d10`).
3. **Structure.** Правила — Markdown, каталоги — JSON. У каждой страницы и записи есть ссылка на книгу и страницу; для дополнительных книг — `sourceBook`.
4. **Verify.** Zod-схемы, проверка уникальности, сверка таблиц с координатами и рендерами.
5. **Build.** VitePress собирает статику; Pagefind индексирует; плагин генерирует `llms.txt`, после чего `tools/llms/enrich.ts` дополняет их данными каталогов.

### Правила переноса текста

- Формулировки не переписываем.
- Исправляем только механические артефакты OCR и переносы строк.
- Врезки и цитаты выносим в `::: info` / `::: tip` с сохранением авторства.
- У каждой страницы указываем `Источник: стр. N`; для дополнительной книги — ещё и её название.
- У каждой записи каталога — `sourcePage`, для дополнительных книг — `sourceBook`.
- Спорные места сверяем с изображением страницы.

## Данные

- `docs/.vitepress/data/*.json` — каталоги.
- `docs/.vitepress/schemas/*.ts` — Zod-схемы.
- `schemaVersion` в каждом файле — для будущих миграций.
- Древа профессий: `docs/.vitepress/data/profession-trees.json` (16 профессий, 144 способности и определяющие навыки).
- Иконки субстанций: `_artifacts/web/assets/icons_svg/` (векторные, из Foundry-репозитория; атрибуция в `_artifacts/web/assets/ICONS.md`).

## LLM-версия

`vitepress-plugin-llms` генерирует `llms.txt`, `llms-full.txt` и Markdown-версию каждой страницы. Каталоги рендерятся Vue-компонентами, поэтому плагин не видит их содержимое в исходном Markdown. После сборки `tools/llms/enrich.ts` дописывает в LLM-файлы данные из JSON-каталогов: заклинания и их эффекты, блоки характеристик чудовищ, таблицы снаряжения, чертежи, профессии и древа. Благодаря этому страницы, на которые ссылается `llms.txt`, не остаются пустыми.

## Деплой

Проект размещён на Vercel: **https://witcher-rules.vercel.app**

- Build Command: `npm run check` (валидация каталогов, сборка и дополнение LLM-версии)
- Output Directory: `docs/.vitepress/dist`
- Node.js 22+ (текущий билд Vercel — 24.x)

`vercel.json` содержит настройки. `sitemap.hostname` и `robots.txt` указывают на `https://witcher-rules.vercel.app`.

### Vercel CLI

```bash
npx vercel login                     # авторизация в аккаунте Vercel
npx vercel link --yes                # привязать каталог к проекту
npx vercel deploy --target=preview   # preview-деплой
npx vercel deploy --prod             # production-деплой
```

`.vercel/` исключён из Git. Для CI можно передать `VERCEL_TOKEN` через переменную окружения.
