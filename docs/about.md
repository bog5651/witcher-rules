# О проекте

Это неофициальный справочник по настольной ролевой игре «Ведьмак». Его задача — сделать правила удобными для поиска и использования за столом, не меняя их формулировки.

## Источник

Основной источник — русское издание книги правил «Ведьмак: Настольная ролевая игра» (R. Talsorian Games, CD PROJEKT RED; локализация Hobby World, ISBN 978-5-907170-26-1).

Текст правил переносится из книг с сохранением формулировок. Исправляются только механические артефакты распознавания: переносы строк, колонтитулы, обозначения бросков (`1d6`, `2d6+2`) и очевидные ошибки OCR. Каждая страница указывает книгу и страницы источника.

## Права

«Ведьмак» и связанные названия — торговая марка CD PROJEKT S.A. Права на текст правил принадлежат R. Talsorian Games и Hobby World. Сайт не связан с правообладателями и не получает прибыли от публикации.

Если вы правообладатель и хотите обсудить размещение материалов — свяжитесь с автором проекта.

## Как устроен сайт

- VitePress + Vue 3, статическая сборка.
- Markdown для правил, JSON для каталогов.
- Схемы данных проверяются перед сборкой.
- Текст сверяется с PDF постранично.
