# О проекте

Это неофициальный справочник по настольной ролевой игре «Ведьмак». Его задача — сделать правила удобными для поиска и использования за столом, не меняя их формулировки.

## Источник

Основной источник — русское издание книги правил «Ведьмак: Настольная ролевая игра» (R. Talsorian Games, CD PROJEKT RED; локализация Hobby World, ISBN 978-5-907170-26-1).

Дополнительные источники: «The Witcher: A Tome of Chaos» / «Том Хаоса», «Alzur's Tome of Magic», «Снаряжение Ведьмака», «Фургончик Родольфа. Инструменты мастеров», каталоги оружия, брони и алхимии версии 2, «Магические дары / Тактические погони», а также неофициальный «Монстрятник» (помечен как неофициальный). В каталогах и на страницах указано, из какой книги и с какой страницы взят текст.

Текст правил переносится из книг с сохранением формулировок. Исправляются только механические артефакты распознавания: переносы строк, колонтитулы, обозначения бросков (`1d6`, `2d6+2`) и очевидные ошибки OCR. Каждая страница указывает книгу и страницы источника. Номера страниц — по печатной нумерации книги; в PDF дополнительных книг они могут отличаться на одну страницу.

## Права

«Ведьмак» и связанные названия — торговая марка CD PROJEKT S.A. Права на текст правил принадлежат R. Talsorian Games и Hobby World. Сайт не связан с правообладателями и не получает прибыли от публикации.

Если вы правообладатель и хотите обсудить размещение материалов — свяжитесь с автором проекта.

## Как устроен сайт

- VitePress + Vue 3, статическая сборка.
- Markdown для правил, JSON для каталогов.
- Схемы данных проверяются перед сборкой.
- Текст сверяется с PDF постранично.
