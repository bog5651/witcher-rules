# Формулы

У каждого алхимического состава в настольной ролевой игре «Ведьмак» есть формула — рецепт, в котором указаны все необходимые ингредиенты и описан процесс изготовления. Если у алхимика есть перед глазами написанная на листе бумаги формула, он получает бонус +2 к проверке навыка Алхимия для создания этого состава.
