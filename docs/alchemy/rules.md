# Правила

## Система алхимии

Процесс изготовления алхимических составов в мире «Ведьмака» состоит из трёх обязательных шагов:

1. Поиск нужной формулы.
2. Поиск нужных ингредиентов.
3. Проверка Алхимии.

## Поиск нужной формулы

У каждого алхимического состава в настольной ролевой игре «Ведьмак» есть формула — рецепт, в котором указаны все необходимые ингредиенты и описан процесс изготовления. Если у алхимика есть перед глазами написанная на листе бумаги формула, он получает бонус +2 к проверке навыка Алхимия для создания этого состава.

## Поиск нужных ингредиентов

В формуле всегда указаны вид и количество алхимических субстанций, необходимых для создания состава. Алхимия не уточняет, из какого сырья должна быть получена та или иная субстанция — лишь её количество и пропорции. Также для создания состава понадобятся инструменты алхимика — без них заниматься алхимией невозможно.

## Проверка Алхимии

Когда необходимые ингредиенты собраны, можно приступать к созданию алхимического состава. В формуле указаны время и сложность приготовления. Вначале скажите ведущему, что ваш персонаж затрачивает на это необходимое время. Затем совершите проверку навыка Алхимия со СЛ, равной СЛ формулы. При успехе вашему персонажу удаётся создать одну порцию алхимического состава. При провале он создаёт слишком мало или же допускает ошибку в приготовлении, а потому результат работы ни на что не годен.

## Переработка (необязательно)

Сразу после провала проверки Алхимии у персонажа есть шанс вернуть часть ингредиентов, использованных при изготовлении. Вы можете совершить ещё одну проверку Алхимии со СЛ, равной СЛ формулы. При успехе персонаж получает одну из затраченных субстанций в чистом виде.

::: info Алхимические субстанции
Алхимия основывается на девяти особых алхимических субстанциях. Одну и ту же субстанцию можно извлечь из разных предметов. Для этого алхимики собирают, выкапывают или срезают травы, плоды и другие виды сырья.
:::

::: tip Добыча внутренностей
Знаешь, порой этот мир кажется поистине чудесным местом. Меня восхищает сама мысль о том, что краснолюд вроде меня может заработать сотни крон, попросту продавая кишочки всяких треклятых тварей.
