# Чудовища

Восемьдесят шесть противников из бестиария. Откройте название, чтобы увидеть полный блок характеристик, способности, оружие, добычу и описание. Скелеты, древни и шесть исключительных чудовищ добавлены из «Alzur's Tome of Magic», остальные — из «Монстрятника».

Основная книга: стр. 270–309. Дополнительные чудовища: стр. 54–79 книги «Alzur's Tome of Magic», версия 1.1, и стр. 2–118 книги «Монстрятник. Неофициальный бестиарий для „Ведьмак НРИ“».
