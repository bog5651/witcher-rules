# Чудовища

Девяносто три противника из бестиария. Откройте название, чтобы увидеть полный блок характеристик, способности, оружие, добычу и описание. Скелеты, древни и шесть исключительных чудовищ добавлены из «Alzur's Tome of Magic», 58 записей — из «Монстрятника», ещё 7 — из «Тома Хаоса».

Правила некромантии, включая создание Амальгамы трупов и призыв Кающегося, собраны в разделе [«Некромантия»](/magic/necromancy).

## Трофеи

С убитых чудовищ можно снять часть тела и превратить её в магический трофей. Правила ношения, ритуал наполнения и эффекты по классам чудовищ собраны в разделе [«Трофеи»](/bestiary/trophies).

Основная книга: стр. 270–309. Дополнительные чудовища: стр. 54–79 книги «Alzur's Tome of Magic», версия 1.1; стр. 2–118 книги «Монстрятник. Неофициальный бестиарий для „Ведьмак НРИ“»; стр. 195–208 книги «The Witcher: A Tome of Chaos».
