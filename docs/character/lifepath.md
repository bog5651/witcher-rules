# Жизненный путь

Жизненный путь определяет, откуда родом ваш персонаж, что случилось с его семьёй и какие события повлияли на него до начала приключения. Это делается при помощи нескольких бросков костей; при желании шаг можно пропустить.

::: info Раздел готовится
Таблицы родины, семьи, родителей, положения семьи, друзей и важных событий будут добавлены отдельным каталогом на следующем этапе. Пока доступны [расы](/character/races), [параметры](/character/stats), [навыки](/character/skills), [проверки](/character/checks), [развитие](/character/development) и [репутация](/character/reputation).
:::
