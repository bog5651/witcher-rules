# Пороги навыков

**Основа** — это сумма значений соответствующего параметра и навыка вашего персонажа. При проверке навыка основа добавляется к результату броска (см. [«Проверки навыков»](/character/checks)). Описания показывают, чего персонаж достигает при данном значении основы; сложность конкретной задачи задаёт СЛ проверки.

Навыки с пометкой **(2)** — сложные: их повышение требует вдвое больше очков (см. [«Навыки»](/character/skills)). Перечень навыков и пометки сложных приведены на стр. 49 книги; ниже — описания всех 50 навыков в порядке параметров.
