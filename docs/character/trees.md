# Древо навыков

У каждой профессии в настольной ролевой игре «Ведьмак» есть древо навыков, состоящее из трёх ветвей. Каждая ветвь представляет собой какое-то одно направление данной профессии. «Корнем» такого древа служит определяющий навык профессии.

::: info Раздел готовится
Древа навыков будут добавлены вместе с профессиями: у каждой из девяти профессий — определяющий навык и три ветви способностей.
:::
