# Глоссарий

Короткие расшифровки, чтобы не листать книгу за каждым сокращением.

## Параметры

| Сокращение | Термин | Что означает |
|---|---|---|
| Инт | Интеллект | Решение загадок, исследования, дедукция |
| Реа | Реакция | Бой, уклонение, быстрые движения |
| Лвк | Ловкость | Дистанционные атаки, координация, равновесие |
| Тел | Телосложение | Сила, выносливость, сопротивление болезни |
| Скор | Скорость | Как быстро персонаж передвигается |
| Эмп | Эмпатия | Соблазнение, убеждение, эмоции |
| Рем | Ремесло | Механизмы, ловушки, создание вещей |
| — | Воля | Психическая выносливость, запугивание, магия |
| — | Удача | Очки, которые можно добавить к броску |

## Мир

| Термин | Значение |
|---|---|
| Континент | Известная часть мира, разделённая между Нильфгаардом, Королевствами Севера и Скеллиге |
| Королевства Севера | Государства Севера, противостоящие Нильфгаарду |
| Нильфгаард | Империя на юге, ведущая экспансию на север |
| Скеллиге | Островное государство, союзное Северу |
| Старшие Народы | Эльфы, краснолюды, гномы и другие нелюди |
| Aen Seidhe | Эльфы, древний народ Континента |
| Скоя’таэли | Партизанские отряды, в основном из эльфов; «белки» |
| Сопряжение Сфер | Катастрофа, открывшая двери между мирами и впустившая магию и чудовищ |
| Исток | Человек или эльф, рождённый с большим нестабильным магическим даром |
| Двимерит | Металл, подавляющий магию |
| Ведьмак | Искусственно созданный мутант, охотник на чудовищ |
| Школы ведьмаков | Волк, Кот, Грифон, Змея и Медведь |
| Ложа Чародеек | Тайная организация чародеек, основанная Филиппой Эйльхарт |
| Братство Чародеев | Первая организация великих магов, разрушенная на Танедде |

## Правила

| Термин | Значение |
|---|---|
| Основа | Сумма параметра и навыка |
| Проверка навыка | 1d10 + основа против СЛ или встречной проверки |
| Встречная проверка | Сравнение результатов двух проверок; при равенстве побеждает защищающийся |
| Очки Улучшения | Ресурс для повышения навыков и параметров |
| Репутация | Известность персонажа, влияющая на отношение окружающих |
| Социальный статус | Отношение общества, зависящее от расы персонажа |
| Порог ранения | Значение ПЗ, ниже которого Реа, Лвк, Инт и Воля снижаются вдвое |
| При смерти | Состояние при ПЗ ниже 0, требующее испытаний против смерти |
| Стабилизация | Первая помощь, возвращающая находящемуся при смерти 1 ПЗ |
| Несмертельный урон | Урон, который лишает сознания, но не убивает |
| Критическое ранение | Тяжёлая травма с дополнительным уроном и последствиями |

| Термин | Значение |

| Ритуал | Длительное магическое действие с компонентами и проверкой |
| Порча | Вредоносная магия, требующая условия снятия |
| Место силы | Источник Хаоса, усиливающий магию |
| Мутаген | Вещество из чудовища для дополнительных мутаций ведьмака |
| Реликвия | Уникальный мощный предмет с историей |
| Руна | Усиление, наносимое на оружие |
| Глиф | Усиление, наносимое на броню |
| Формула | Рецепт алхимического состава |
| Чертёж | Инструкция для создания ремесленного предмета |
| Субстанция | Одна из девяти алхимических категорий |
| Компонент | Материал для ремесла |
