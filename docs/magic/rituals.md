# Ритуалы

Ритуалы — шаблонная форма магии. Для них нужны компоненты, время на подготовку и проверка Проведения ритуалов. Помимо ритуалов основной книги здесь собраны ритуалы некромантии из «Alzur's Tome of Magic» и ритуалы из «Тома Хаоса».

<MagicCatalog dataset="rituals" />

::: info Ингредиенты
Для проведения многих ритуалов требуются предметы, которые не считаются ингредиентами и которых нет в списках раздела «Субстанции». Такие предметы, вроде крепкого алкоголя и мелков, можно найти в разделе «Снаряжение» на стр. 93. Ингредиенты считаются потраченными независимо от того, удался ритуал или нет. Единственное исключение — телекоммуникатор.
:::

::: info Источник
Основная книга: стр. 116–119. Ритуалы некромантии: стр. 30–32 книги «Alzur's Tome of Magic», версия 1.1. Ритуалы из «Тома Хаоса»: стр. 102–104.
:::
