# Знаки

Ведьмачьи знаки — простая форма магии, доступная персонажам с ведьмачьей подготовкой. Ниже — базовые знаки и дополнительные варианты из книги.

<MagicCatalog dataset="signs" />

::: info Меняющиеся затраты Вын
Из-за простоты ведьмачьих знаков заклинатель может вложить в них столько сил, сколько пожелает (максимум 7 очков Вын), пока это количество не превышает значение Энергии заклинателя. Эффекты знака усиливаются, если при сотворении вложить в него больше очков Вын.
:::

::: info Изучение знаков
Ведьмачьи знаки крайне просты, и для того чтобы их сотворить, требуется совсем немного магической силы. Другие адепты магии с лёгкостью могут ими пользоваться (базовые знаки эквивалентны заклинаниям и инвокациям уровня новичка). Дополнительные виды знаков изучить несколько сложнее (они эквивалентны заклинаниям уровня подмастерья).
:::
