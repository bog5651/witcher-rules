# Заклинания

Заклинания сгруппированы по уровню сложности и стихии. Фильтры работают по названию и тексту эффекта, а бейдж источника показывает книгу и страницу. В каталог входят заклинания основной книги и новые заклинания из «Alzur's Tome of Magic»; часть названий в источнике дана по-английски и сохранена без перевода.
