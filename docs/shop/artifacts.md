# Магические артефакты

Артефакты — это уникальные магические предметы с именем, историей и собственными правилами. Они не продаются в обычных лавках и не заменяют реликвии основной книги: реликвии остаются в разделе [«Руны и реликвии»](/crafting/runes), а здесь собраны предметы из дополнительных книг.

Магическая броня и оружие, у которых есть обычные игровые характеристики, остаются в каталогах [оружия](/shop/weapons) и [брони](/shop/armor). В этот раздел попадают только предметы, для которых важна именно уникальная магическая природа.
