# Компоненты

В данной игре мы используем единицы в качестве меры количества (это куда более определённое обозначение, чем унции, литры или граммы). Единицы обозначают количество порций компонента, которое персонаж получает из определённого источника. В таблицах цена каждого компонента указана за единицу. Колонка «Количество» относится только к собирательству.

Персонаж может совершить проверку Выживания в дикой природе со СЛ, зависящей от СЛ собирания компонента, чтобы попытаться найти его в дикой местности. Персонаж должен находиться в том месте, где этот компонент встречается. При успехе он получает указанное количество единиц этого компонента. Время, уходящее на собирание компонента, определяет ведущий, основываясь на доступности данного компонента и месте поиска.
