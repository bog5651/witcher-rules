# Вещи

Некоторые вещи проще сделать с помощью подходящих инструментов, а некоторые и вовсе невозможны без них. Наборы инструментов — это небольшие или среднего размера комплекты различных инструментов, которые помогут персонажу справиться с разными задачами. Некоторые инструменты (для ловли рыбы или нанесения макияжа) добавляют бонусы при выполнении задачи. Другие (для алхимии и подделывания) для работы попросту необходимы.
