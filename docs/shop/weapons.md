# Оружие

120 позиций: 56 из основной книги и 64 из дополнительных книг — 52 из «Каталога оружия, версия 2» и 12 ведьмачьих мечей шести школ из «Снаряжения Ведьмака». Ведьмачьи мечи не продаются: их изготавливают по чертежу. Отметьте предметы, чтобы посчитать общий вес и стоимость. Нажмите на название, чтобы открыть карточку с описанием и всеми характеристиками. Бейдж рядом с названием показывает книгу и страницу источника; полное название книги — во всплывающей подсказке.

::: details Как читать характеристики оружия
**Тип (Т).** Показывает, какой урон наносит оружие. Всего есть 4 типа урона: режущий (Р), колющий (К), дробящий (Д) и стихийный (С). Тип оружия важен, поскольку у многих чудовищ и доспехов есть сопротивление определённому типу урона.

**Точность (Т).** Показывает, насколько хорошо сбалансировано оружие. Совершая атаку по цели, прибавьте точность оружия к результату проверки атаки.

**Доступность (Дос).** Показывает, насколько легко найти такое оружие в продаже и насколько часто его можно увидеть на поле боя. Повсеместное (П): можно найти даже в небольших посёлках. Обычное (О): можно найти на рынках большинства городов. Редкое (Р): оружие для армии или изготавливаемое только в определённых местах. Уникальное (У): очень трудно найти, обычно продаётся только в одном месте или у определённых торговцев.

**Урон (У).** Показывает, насколько серьёзные раны можно нанести этим оружием при попадании. Урон зависит от размера, остроты, веса и балансировки оружия.

**Надёжность (Н).** Показывает, насколько крепко оружие, то есть сколько раз им можно блокировать удар, прежде чем оно сломается.

**Хват (X).** Показывает, сколько нужно свободных рук, чтобы держать это оружие. Двуручное оружие можно держать в одной руке со штрафом -3. Помните, что для перезарядки ручных арбалетов всё равно требуются обе руки. Щит держат в одной руке.

**Дистанция (Дис).** Показывает расстояние, с которого вы можете атаковать противника. Для конкретного вида оружия указана его дальняя дистанция. «Нет» означает, что цель должна быть рядом.

**Эффект.** Показывает, есть ли у оружия дополнительные свойства. Описание всех эффектов — во всплывающих подсказках.

**Скрытность (Скр).** Показывает, где можно спрятать оружие. Маленькое (М): можно спрятать в кармане. Небольшое (Н): можно спрятать под курткой. Крупное (К): можно спрятать под плащом. Не спрятать (Н/С): невозможно спрятать под одеждой.

**Усиление (Ус).** Показывает, сколько рун можно нанести на оружие.

**Вес.** Вес оружия в килограммах.

**Цена.** Цена оружия в реданских кронах.
:::

## Эффекты оружия

У оружия бывают дополнительные свойства — эффекты. В каталоге они перечислены в графе «Эффект», а ниже приведены их описания со стр. 72.

| Эффект | Описание |
|---|---|
| Незаметное | Это оружие легко спрятать. Вы получаете бонус +2 при попытке скрыть это оружие. |
| Кровопускающее (х) | Если это оружие нанесёт урон цели, с определённой вероятностью оно может вызвать кровотечение. Вероятность кровотечения указана в скобках. См. описание эффекта кровотечения на стр. 161. |
| Пробивающее броню | Такое оружие игнорирует сопротивление урону любой брони, по которой оно попадает. Улучшенное пробивающее броню оружие помимо этого игнорирует половину прочности брони. |
| Дезориентирующее (х) | Когда этим оружием наносят удар по туловищу или голове, противник должен совершить испытание Устойчивости, к которому применяется штраф, указанный в скобках. |
| Метеоритное | Это оружие наносит полный урон чудовищам, уязвимым к метеоритной стали. Также такое оружие имеет 5 дополнительных пунктов надёжности. |
| Длинное | Этим оружием можно атаковать противников в пределах 2 метров. |
| Фокусирующее (X) | При сотворении магии с помощью этого оружия вычтите его значение фокусировки из стоимости заклинания в Вын. |
| Улучшенное фокусирующее | При сотворении заклинаний с помощью этого оружия СЛ проверок против ваших заклинаний считается на 2 выше. |
| Захватное | Это оружие можно использовать для захвата и подсечки противника в пределах дистанции. |
| Медленно перезаряжающееся | Для перезарядки этого оружия требуется 1 действие. |
| Несмертельное | Это оружие можно использовать для нанесения несмертельного урона без штрафов. |
| Сбалансированное | При нанесении критического ранения этим оружием бросьте 2d6 + 2 для определения места этого ранения. Если атака была прицельной, бросьте 1d6 + 1 вместо 1d6 для определения серьёзности критического ранения. |
| Разрушающее | При попадании это оружие наносит 1d6/2 урона прочности брони. |
| Рукопашное | Такое оружие использует навык Борьба. Его урон прибавляется к урону от атаки без оружия. |

## Боеприпасы

Боеприпасы подходят к лукам и арбалетам. Разные наконечники лучше работают против разных целей, поэтому их стоит подбирать под противника.

**Н** — надёжность, **Дос** — доступность (П/О/Р/У).

## Улучшения арбалета

На ручные арбалеты можно установить лишь одну модификацию, тогда как все прочие виды допускают установку сразу двух. Любые модификации сперва необходимо установить на арбалет ценой действия полного хода. Будучи установленной на арбалет, модификация также требует действия полного хода для её снятия. На один арбалет можно установить не более одной модификации каждого типа.

**Дос** — доступность (П/О/Р/У).

## Улучшения оружия

Опытные ремесленники могут улучшать снаряжение. Эти улучшения не занимают ячейки Ус.

| Улучшение | Эффект | Цена у ремесленника |
|---|---|---:|
| Укрепление | +2 к надёжности | 49 |
| Зазубривание / шипы | +25% к вероятности кровотечения | 51 |
| Облегчение | +1 к точности | 53 |
| Серебрение 10 или менее стрел | Получает эффект Серебряное (1d6) | 125 |
| Серебрение одноручного оружия | Получает эффект Серебряное (2d6) | 200 |
| Серебрение двуручного оружия | Получает эффект Серебряное (2d6+2) | 340 |
